# Security

Report a vulnerability privately through GitHub's private vulnerability
reporting: the **Security** tab of
[polybjorn/audio-lang-tagger](https://github.com/polybjorn/audio-lang-tagger/security/advisories/new),
then **Report a vulnerability**. Please do not open a public issue for it.

Only the latest release is supported: the one
[releases/latest](https://github.com/polybjorn/audio-lang-tagger/releases/latest)
points to. Pre-releases and `main` are not.
